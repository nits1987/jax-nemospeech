# External parity fixtures

`loss-smoke --fixture PATH` accepts an uncompressed NumPy `.npz` produced by the pinned NeMo/reference environment. Required arrays are:

- `logits`: float32 `[B,T,U+1,V]` classic RNN-T logits;
- `labels`: integer `[B,U]` targets, with no blank in valid positions;
- `logit_lengths`: integer `[B]`;
- `label_lengths`: integer `[B]`;
- `blank_id`: scalar integer;
- `expected_loss`: scalar or `[B]`, matching `reduction`;
- `reduction`: optional scalar string, default `mean_batch`;
- `expected_logits_grad`: float32 array matching `logits`.

Both the reference loss and logit gradient are mandatory for an external fixture, so a value-only comparison cannot be reported as parity. Keep fixtures small enough that the vocabulary lattice is an appropriate correctness oracle. Real-shape TPU qualification should use the frame-wise joint API and record HBM separately.

Every fixture used as evidence must be accompanied by the source lock, generator revision, input/checkpoint hashes, NeMo version, precision, and shape metadata. A synthetic fixture generated by this package is a smoke test, not NeMo parity evidence.
